# Programming-for-Data-Science

## Bikeshare Data Exploration

### Date created
This project and README were created on July 30, 2026.

### Description
This project uses Python to explore data related to bike share systems for
three major US cities: Chicago, New York City, and Washington. The script
imports the data and answers interesting questions about it by computing
descriptive statistics. It also takes in raw user input to create an
interactive experience in the terminal that presents these statistics.

The program reports:
- Popular times of travel (most common month, day of week, and start hour)
- Popular stations and trip (most common start station, end station, and trip)
- Trip duration (total and average travel time)
- User info (counts of user types, and gender and birth year where available)
- Raw data displayed five rows at a time on request

### Files used
- bikeshare.py
- chicago.csv, new_york_city.csv, washington.csv (excluded via .gitignore)

### How to run
python bikeshare.py
